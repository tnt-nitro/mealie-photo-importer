# 1.1 Dateiauswahl (Windows) | File Selection (Windows)

## Deutsch

**Ziel:**  
Ein Bild vom lokalen Windows-System auswählen und laden.

**Funktion:**  

- Öffnen eines Windows-Dateidialogs  
- Auswahl einer Bilddatei (z. B. JPG, PNG)  
- Laden des Bildes in das Tool

**Ergebnis:**  

- Bild ist im Speicher verfügbar  
- Grundlage für OCR-Verarbeitung

**Nicht-Ziele:**  

- Keine OCR-Verarbeitung  
- Kein Upload zu Mealie  
- Keine Bildbearbeitung

---

## English

**Goal:**  
Select and load an image from the local Windows system.

**Function:**  

- Open a Windows file dialog  
- Select an image file (e.g. JPG, PNG)  
- Load the image into the tool

**Result:**  

- Image is available in memory  
- Basis for OCR processing

**Non-goals:**  

- No OCR processing  
- No upload to Mealie  
- No image editing
