# 1.2 OCR-Rohtext anzeigen | Display OCR Raw Text

## Deutsch

**Ziel:**  
Den aus dem Bild erkannten Text (OCR) roh und unverändert anzeigen.

**Funktion:**  

- Übergabe des geladenen Bildes an die OCR-Engine  
- Anzeige des erkannten Textes als reiner Text (ohne Nachbearbeitung)

**Ergebnis:**  

- OCR-Rohtext ist sichtbar  
- Grundlage für spätere Analyse und Parsing

**Nicht-Ziele:**  

- Keine Strukturierung des Textes  
- Keine automatische Rezept-Erkennung  
- Kein Upload zu Mealie

---

## English

**Goal:**  
Display the raw text recognized from the image using OCR.

**Function:**  

- Pass the loaded image to the OCR engine  
- Display the recognized text as plain, unprocessed text

**Result:**  

- OCR raw text is visible  
- Basis for later analysis and parsing

**Non-goals:**  

- No text structuring  
- No automatic recipe detection  
- No upload to Mealie
